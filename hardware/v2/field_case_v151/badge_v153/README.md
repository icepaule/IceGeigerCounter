# IceGeiger Rear Badge v1.5.3 – ACE two-color

This revision keeps the Field Case v1.5.1 mechanics unchanged and corrects the rear-badge project label from `IceDrone` to **`IceGeiger`**.

## ACE color assignment

- `IceGeiger_Badge_v1.5.3_BASE.stl` – black
- `IceGeiger_Badge_v1.5.3_LOGO_TEXT.stl` – yellow / fluorescent yellow

Both meshes use the same coordinate system. Import them as **parts of one object** in Anycubic Slicer Next and assign the two ACE filaments to the corresponding parts.

A ready-to-import multi-part 3MF is generated under `3mf/IceGeiger_Badge_v1.5.3_ACE_2COLOR.3mf`.

## Geometry

- badge: 78 × 24 mm
- base thickness: 1.20 mm
- artwork key depth: 0.40 mm
- visible artwork height above base: 0.90 mm
- text: `IceGeiger`, 6.0 mm, centered in the free right-hand badge area

The 0.40-mm interlock gives the second-color artwork a mechanical key into the background plate instead of placing it only on the top surface.

## Historical version

`badge_v152/` remains in the repository for reproducibility but contains the superseded `IceDrone` label. Use **v1.5.3** for new prints.
